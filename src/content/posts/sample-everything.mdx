## Inline formatting

This paragraph holds **bold text**, *italic text*, ***bold italic text***, ~~struck-through text~~ and `inline code`. The same emphasis written with underscores, __bold__ and _italic_, looks identical. A code span can hold backticks, like `` `this` ``, and a long one, like `const value = readSettings(entry).withEveryOptionTurnedOn(true, false, null)`, wraps or scrolls with the text.

Links come in several forms: a [plain link](https://example.com/), a [link with a title](https://example.com/ "A title shown on hover"), a [link to another page on this site](/writing/), a [link to a heading on this page](#a-wide-table) and a bare address that becomes a link by itself, https://example.com/a/bare/address. A footnote reference sits at the end of this sentence.[^1]

Smart punctuation turns "straight double quotes" and 'straight single quotes' into curly ones, two hyphens -- like these -- into an en dash, three hyphens --- like these --- into an em dash, and three dots... into an ellipsis. Characters that would otherwise be Markdown can be escaped: \*not italic\*, \_not italic\_, \# not a heading, \[not a link\] and 1\. not a list. Entities work too: &copy; 2026, 10&nbsp;km, caf&eacute;.

Inline HTML covers what Markdown has no syntax for: H<sub>2</sub>O and E = mc<sup>2</sup>; the <abbr title="Content Security Policy">CSP</abbr> abbreviation; keyboard keys like <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>; <mark>highlighted text</mark>; <small>small print</small>; <ins>inserted text</ins> and <del>deleted text</del>; and <cite>a cited work</cite>.

A hard line break ends this line with a backslash,\
so the next sentence starts on a new line inside the same paragraph.\
And one more line after that.

A very long unbroken word, such as Pneumonoultramicroscopicsilicovolcanoconiosissupercalifragilisticexpialidocious_with_a_tail_on_the_end, wraps inside the column instead of pushing the page sideways.
