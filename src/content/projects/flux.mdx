<Chapter stage="problem" visual="screenshot" draft>

Two newsletters, Convergence and Drift, share one Ghost site. A stock theme shows them as one list of posts with one colour and one subscribe button.

The aim was a theme where each newsletter has its own look and its own archive, and where a post can offer the reader more than the text.

</Chapter>

<Chapter stage="constraints" draft>

Each newsletter needed its own colour, timeline and subscribe button, driven by Ghost's own settings rather than a hard-coded list.

The site runs on Magic Pages, a hosted Ghost service, so everything had to live in the theme and in Ghost's routes and redirects files.

Dark mode had to offer light, dark and follow-the-system, and switch without a flash of the wrong theme.

AI-generated text on a page is a risk, so anything a model writes had to be sanitised, and the theme had to keep content security policy headers and integrity hashes on its scripts.

</Chapter>

<Chapter stage="options" draft>

Three routes were open. Only one of them could give the two newsletters their own identity without working against the theme.

</Chapter>

<Chapter stage="built" visual="architecture" draft>

Flux is a Ghost theme written in Handlebars with Tailwind v4. Drift is lavender and Convergence is sage, each with its own archive, timeline and subscribe button, and other tags take their accent colour from Ghost.

A Node.js build minifies the scripts and stamps them with subresource integrity hashes. AI-generated content passes through DOMPurify before it reaches the page.

AI reading aids are optional. A Supabase Edge Function asks a model for critical questions and related topics about a post, and members can regenerate them with higher-tier models.

Development runs in a GitHub Codespace that starts a local Ghost, pulls real content from production and deploys the theme through GitHub Actions.

<Chapter stage="outcome" draft>

Flux has been the live theme on doncoleman.ca since 2025. Each newsletter reads as its own publication, and the dark mode toggle holds its state across pages.

The Codespaces workflow means a new environment with real content is a few minutes away, which is described in the post on [self-contained development for Ghost themes](/writing/self-contained-development-for-ghost-themes/).

This site replaces the Ghost blog, so Flux retires with it. The split-screen picture above is its record, and the lessons carried over into the design of this site.

</Chapter>

<Chapter stage="lessons" draft>

A hosted Ghost site cannot run a server, so the AI backend had to live somewhere else. It moved from an Express.js gateway to Supabase Edge Functions, which was less to run.

Content security headers and integrity hashes were worth adding early. Retrofitting them to a theme that already loaded scripts freely would have been slower.

</Chapter>
