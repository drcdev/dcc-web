# Chore plan: dependabot-sharp-source-map

Branch: `chore/dependabot-sharp-source-map`, from `main` at 67fc616 (after #131 merged).
Issue: none. This is an ad-hoc chore. The PR body names the two Dependabot alerts it clears.

## Goal

Clear the two open Dependabot alerts on `main`. Alert #4 is `sharp` <0.35.5
(GHSA-wq5f-xc86-pv6w, high, librsvg). It comes in only through Cloudflare's dev tooling
(`wrangler>miniflare>sharp` and `worker>@cloudflare/vitest-plugin>{,wrangler>}miniflare>sharp`),
which locks `sharp@0.35.4`. Alert #3 is `source-map-js` >=1.0.0 <1.2.2 (GHSA-68fv-2mgg-jv7q,
high), which comes in by range through postcss, `@tailwindcss/node`, css-tree and magicast. The
fix is to bump `wrangler` 4.144.0 → 4.149.0 and `@cloudflare/vitest-plugin` 1.3.3 → 1.4.0
together. Both pin `miniflare@5.20261006.1-alpha`, which pins `sharp@0.35.5`. Then refresh
`source-map-js` to 1.2.2 inside its existing ranges, as a lockfile-only change. Astro's own
`sharp` (root `package.json`, already 0.35.5) does not change, so built pages and images are
the same before and after. Alert #2 (`postcss-selector-parser` <7.1.6, GHSA-rj75-hqrm-r3gf,
via `@tailwindcss/typography@0.5.20`, which pins `6.0.10` exactly) was dismissed by Don as not
reachable and is **out of scope**.
