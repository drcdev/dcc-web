**Tests are mandatory** (Constitution Principle I). Within every phase, test tasks come first and each says the test must be run and **seen to fail** before the implementation tasks that follow. A task is never marked done on a red suite.

## Format: `- [ ] [TaskID] [P?] [Story?] Description with file path`

- **[P]**: can run in parallel (different files, no dependency on an incomplete task)
- **[Story]**: US1 to US7 (user stories from spec.md)
- **[PREVIEW-CHECK]** suffix: cannot be verified locally; needs the preview deployment or Don's eyes. The implementer leaves these unchecked and lists them in the PR body.
- **SHARED** marks a file other branches (portfolio, contact) also edit. Keep the edit minimal and additive (plan.md § Shared files and parallel work).

## Local toolchain (applies to every task that runs pnpm, astro, playwright or wrangler)

- Node comes from nvm. Run `node -v` first; if it is not the `.nvmrc` version (24), run `source ~/.nvm/nvm.sh && nvm use` in the **same** Bash command as the toolchain call.
- In this worktree use `corepack pnpm` for pnpm commands. macOS has no `timeout`; bound long runs with `perl -e 'alarm N; exec @ARGV' <cmd...>`.
- `pnpm run verify` in an agent shell needs `ASTRO_PREVIEW_BACKGROUND=1`. Sibling worktrees share Playwright port 4321/4322; a mass ECONNREFUSED mid-run is that collision, so rerun when idle.
- Astro decisions: consult the Astro Docs MCP (`astro-docs`) and the pages cited in research.md; if the MCP is unavailable, say so in the task notes and use docs.astro.build.
- Test conventions: Vitest in `tests/unit/`, `tests/component/` (Astro Container API, helpers in `tests/component/html.ts`), `tests/build/` (fixture-site harness `tests/build/fixture-site.ts`); Playwright in `tests/e2e/` (`a11y`, `budget`, `visual`, `sections`, `e2e` projects). The changed-paths drift guard rejects `specs/` path literals in tests: never write a `specs/...` path in a test file; point tests at `docs/`, `src/` or `tests/fixtures/` only.
- Never commit `.reference/`. Dependencies are added with the package manager, never by hand-editing `pnpm-lock.yaml`.
