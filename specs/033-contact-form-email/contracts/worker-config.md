# Contract: Worker configuration (`wrangler.jsonc`) after feature 033

Changes only; everything else in `wrangler.jsonc` (assets, `ai`, observability, D1 bindings,
`workers_dev`/`preview_urls`) is unchanged. Applied only through Workers Builds
(`pnpm run deploy:preview`, `pnpm run deploy:production`), never by hand.

## Top level (production, Worker `dcc-web`)

```jsonc
"triggers": { "crons": [] },                       // removes the 17 3 * * * retention cron on deploy
"secrets": { "required": ["TURNSTILE_SECRET_KEY"] },
"send_email": [
  {
    "name": "CONTACT_EMAIL",
    "destination_address": "contact@doncoleman.ca",
    "allowed_sender_addresses": ["contact-form@drc.dev"]
  }
]
```

## `env.preview` (Worker `dcc-web-preview`)

```jsonc
"vars": { "ALLOW_TURNSTILE_TESTING": "true", "SITE_ENVIRONMENT": "preview" },
"triggers": { "crons": [] },
"secrets": { "required": ["TURNSTILE_SECRET_KEY"] },
"send_email": [ /* identical to the top-level block */ ]
```

Bindings and vars are not inherited by wrangler environments, so the preview block repeats them.

## Invariants (asserted by `tests/unit/site/config-files.test.ts`)

- Exactly one `send_email` binding per environment, named `CONTACT_EMAIL`.
- Its `destination_address` equals `CONTACT_DESTINATION`, and `allowed_sender_addresses` equals
  `[CONTACT_SENDER]` (constants from `worker/src/contact/email.ts`), in both environments.
- No `remote: true` on the binding (it would send real mail from `wrangler dev`).
- `triggers.crons` is present and empty in both environments (not omitted: omitted leaves the
  deployed cron in place).
- `secrets.required` is exactly `["TURNSTILE_SECRET_KEY"]` in both environments.
- `SITE_ENVIRONMENT` is `"preview"` in `env.preview.vars` and absent from production.

## Derived files

- `worker/worker-configuration.d.ts`: regenerated with `pnpm run types:worker`; `Env` gains
  `CONTACT_EMAIL: SendEmail` and `SITE_ENVIRONMENT`, loses `CONTACT_READ_TOKEN` and
  `IP_HASH_SALT`. `pnpm run typecheck` fails if it is stale.
- `wrangler.e2e.json` (generated by `scripts/e2e-wrangler-config.ts`, gitignored): keeps
  `send_email` (local simulation, no login). Fallback if `wrangler dev` cannot run it offline:
  delete it there like `ai` (research R10).

## Migrations

`migrations/0003_drop_messages.sql`: `DROP TABLE IF EXISTS messages;`. Applied to the preview
database by every branch's preview build and to production on `main`.
