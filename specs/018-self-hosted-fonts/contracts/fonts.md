# Contract: fonts in the built site and on the wire

**Feature**: `018-self-hosted-fonts`. Row ids (`F01` …) are cited in test titles; test files
must not contain `specs/...` path literals (the changed-paths drift guard rejects them).

## Page head (every page; BaseLayout)

| Row | Rule |
|---|---|
| F01 | The `<head>` holds one `<style>` emitted by `<Font cssVariable="--font-inter">` with exactly four Inter `@font-face` rules for one family: (400, normal), (400, italic), (700, normal), (700, italic); plus exactly four metric-adjusted fallback `@font-face` rules generated by `optimizedFallbacks`, one per Inter face, in the families `Inter-<hash> fallback: Arial` (400 normal, 400 italic) and `Inter-<hash> fallback: Arial Bold` (700 normal, 700 italic). |
| F02 | Each Inter `@font-face` has `font-display: swap`, `unicode-range` equal to `INTER_UNICODE_RANGE`, and one `src` of the form `url("/_astro/fonts/<hash>.woff2") format("woff2")`, with no `local()`. Each fallback `@font-face` has only a `local("Arial")` (400) or `local("Arial Bold")` (700) `src`, no `url()`, the same weight, style and `font-display` as its Inter face, no `unicode-range` (Astro emits none, so a fallback face covers every character; research R6), and a `size-adjust` (plus whichever of `ascent-override`, `descent-override`, `line-gap-override` Astro computes). No other `@font-face`. |
| F03 | The same `<style>` sets `--font-inter` on `:root` to the Inter family, then the two fallback families (Arial, then Arial Bold), then `SYSTEM_FONT_STACK` in order: today's families with the generic `sans-serif` last. |
| F04 | Exactly two `<link rel="preload" as="font" type="font/woff2" crossorigin>` elements, for the 400 normal and 700 normal files. No preload for the italic faces. |
| F05 | No `href`, `src` or `url()` in the head points at another origin for fonts or stylesheets. |
| F06 | The page CSP meta keeps `font-src 'self'` and `style-src 'self'` plus `sha256-` hashes only (one more hash than today, for the `<Font />` style). No source is added. |

## Served responses (wrangler dev, as production)

| Row | Rule |
|---|---|
| F10 | `GET /_astro/fonts/<hash>.woff2` returns 200, `Content-Type: font/woff2`, `Cache-Control: public, max-age=31536000, immutable`, and the full `/*` security header set. |
| F11 | Other files under `/_astro/` (for example the page stylesheet) do not carry `immutable` or `max-age=31536000`; their caching is unchanged. Superseded by #74: every file under `/_astro/`, including the stylesheet, carries `Cache-Control: public, max-age=31536000, immutable`. |
| F12 | `public/_headers` has four rules: `/*`, `/_astro/fonts/*` (only `Cache-Control`), and the two host rules, unchanged. Superseded by #74: the second rule is `/_astro/*` (only `Cache-Control`). |

## Rendering (browser)

| Row | Rule |
|---|---|
| F13 | Body text is drawn by `Inter-Regular`; `strong` and `font-semibold`/`font-bold`/`font-extrabold` text by `Inter-Bold`; `em`, the block quote and the views note by `Inter-Italic`; `strong em` (bold italic) by `Inter-BoldItalic`; `font-medium` text by `Inter-Regular`; inline `code` by the face its computed weight selects (the prose styles set it to 600, which FR-017 maps to `Inter-Bold`). All report `isCustomFont: true`. |
| F14 | On every budget template, every font response comes from the page's own origin under `/_astro/fonts/`, and no font or stylesheet request goes to any other origin. Each template requests each font file at most once (at most four font requests), and a template requests an italic face only when it draws italic text, and the bold italic only when it draws bold italic text, judged per template from the computed styles of the rendered page (the home tagline is italic, so home does request the italic) (FR-018). |
| F15 | With JavaScript disabled, body text is still drawn by `Inter-Regular` (FR-012). |
| F16 | With font requests blocked, text is visible and drawn by a font whose PostScript name is not `Inter-*` (a metric-adjusted Arial where the machine has Arial, otherwise a system font), and italic text still renders slanted (fallback synthesis, FR-003, FR-005). |
| F17 | Every visual shot is taken after `document.fonts.ready`, with no `FontFace` still loading. |

## Coverage guard

| Row | Rule |
|---|---|
| F18 | Every character in the visual-subject sources is in all four faces' cmap or in the explicit exclusion list (FR-016). |
| F19 | Each committed face's cmap equals the shipped set minus U+00AD, its weight and style match its file name, total bytes ≤ 50,000, and `LICENSE.txt` is the SIL Open Font License. |
